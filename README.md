# Gaurav Kumar — Cinematic Portfolio

A static portfolio inspired by the structure and cinematic feel of the reference portfolio.

## Files
- `index.html` — portfolio page
- `styles.css` — responsive dark/cinematic styling
- `script.js` — smooth scrolling + hero video sound toggle
- `assets/gaurav-intro.mp4` — user's uploaded video
- `assets/Gaurav-Kumar-Resume.pdf` — resume, when available

## Run
Open `index.html` in a browser, or upload the folder to a static host such as GitHub Pages, Netlify, or Vercel.
